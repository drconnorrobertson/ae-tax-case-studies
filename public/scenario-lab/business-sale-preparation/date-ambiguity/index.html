Business sale preparation: Date ambiguity

Expose the different dates the illustration depends on. An illustrative owner is reviewing draft sale terms and the available records.

Fictional, illustrative planning scenario. It does not describe a client, completed engagement or verified savings.

What this file should establish

Separate agreement, payment, transfer, completion and filing dates as relevant. Ask the professional which date controls each decision. Do not use a convenient date simply because the other records are missing.

An illustrative owner is reviewing draft sale terms and the available records.

A situation to work through

The proposed headline price changes while the form of the transaction remains unsettled.

For this situation, start with draft agreement. Identify the period and legal owner before combining it with the other records. Keep the original source and explain any adjustments in a separate reconciliation.

Review point

The after-tax comparison requires the actual structure and source records.

One date is used for several events with different evidence.

Question for the reviewer

Which date facts change the applicable review and what supports them?

Expected handoff

A dated assumption map.

Separate facts supported by documents from estimates and unresolved assumptions. Assign each missing item to a responsible person and a date. Send the reconciliation alongside the source references so the reviewer can trace each conclusion.
